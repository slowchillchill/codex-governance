## 项目合同与治理来源

保留本项目已有的业务、测试、数据用途、权限和维护要求。接入本 Skill 不自动把其公共原则、工程原则
或交接协议设为所有任务的规则；如项目明确长期采用其中某份原则，应单独写明文件、定位方法与适用活动。

## Codex 治理声明

- 本仓库接受用户显式调用 `codex-stage-orchestrator` 并给出明确开发需求，或按该 Skill 声明的 `governance/group-collaboration.md` 接受有效工程委托。只有满足接单条件后才启用开发流程；询问、安装、维护、注册角色、启动 Profile 和收到材料均不构成启动。同一交付继续沿用有效授权，不扩大范围。
- 启用后从实际 Skill 读取开发正文和本组身份要求；本入口不复制角色步骤、验收或关闭条件。其他角色按自己的 Skill 运行，只通过交接协议交换任务和结果。
- 本机绑定、账号和工作站路径保存在仓库外；公开证据使用仓库相对路径。命令权限不扩大职责或破坏性授权，不使用管理员绕过。
